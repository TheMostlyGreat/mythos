## Content Guidelines for LLM Generation

### **Core Reader Experience Goal**

- Must start with action verb (Make, Transport, Immerse, etc.)
- Focus on emotional outcome + genre-specific experience
- Single, compelling sentence that captures genre essence
- Examples: "Make readers laugh out loud while feeling entertained" or "Transport readers to believable future worlds while questioning reality"

### **Essential Craft Questions Format**

- Always use "**How will you...**" or "**What will...**" format
- Focus on practical writer decisions, not theoretical concepts
- Include 3-6 specific examples in brackets after each question
- Questions should be actionable and specific to the genre
- Avoid academic jargon; use plain, practical language

### **Craft Elements to Include (choose 4-5)**

- Primary genre-defining element (magic for fantasy, crime for crime fiction)
- Core structural/plot element (quest structure, mystery solving)
- Character/relationship element (romance chemistry, character psychology)
- Atmosphere/world/context element (world-building, historical accuracy)
- Theme/meaning/impact element (social commentary, emotional resonance)

### **Subgenre Selection**

- Choose 4-6 major subgenres within the main genre
- Focus on significantly different approaches, not minor variations
- Each subgenre gets exactly 2 questions in same format as main questions
- Address subgenre-specific challenges and opportunities

### **Reader Engagement Categories (choose 3-4)**

- Core genre experience (does it deliver what readers came for?)
- Character/emotional connection (do readers care about characters?)
- Craft quality/execution (is it well-written?)
- Genre-specific unique element (varies by genre)

### **Technique Categories**

- Advanced: More sophisticated craft concepts
- Craft Techniques: Practical, hands-on implementation methods
- Focus on how-to rather than theory
- Provide tactical, actionable guidance

### **Final Reminder Paragraph**

- Always start with "\*Remember:"
- Summarize what genre readers seek
- End with "The goal is to..."
- Keep focused on reader experience and practical writing advice
