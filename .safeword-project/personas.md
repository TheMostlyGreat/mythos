# Personas

## Writer

**Role:** A fiction author moving from a loose idea toward a structured story and first-draft manuscript.

**Context:** Works in Mythos as a mobile-first web app (an optional desktop app serves offline or local-storage use). Starts from a rough premise and shapes it through conversation — interview, concept, world-building assets — then steers the draft through the core loop: **choose** at story forks, **redirect** in plain language when no option fits, or **edit** any asset directly as canon. Wants the drudgery removed — blank-page paralysis, continuity bookkeeping, formatting — but the meaningful, expressive decisions kept and staged, because those decisions are the source of ownership. Expects work to persist and resume across sessions.

**Reader mode:** The Writer also reads their finished work in a lean-back mode. Dialing fork density to zero turns the same engine into a near-continuous reading experience, so "Reader" is a mode of the Writer, not a separate persona.

## Deferred roles

Roles that appear in the forward-looking jobs but are not personas we build for today — each becomes real only if Mythos earns its way there.

- **Integrator.** A developer driving the engine programmatically over an MCP server to embed story creation in their own product or workflow (a game-master generating lore, an app embedding generation).
- **Reader (of others' work).** Someone consuming _other_ writers' stories — relevant only if Mythos becomes a content platform rather than a creation tool.
